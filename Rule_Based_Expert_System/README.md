# Rule-Based Expert System

## Project Description
This project is a Rule-Based Expert System developed in Python for disease diagnosis. It uses IF-THEN rules and Forward Chaining to infer possible diseases based on the symptoms entered by the user. The system also displays the reasoning process by showing which rules were matched before arriving at the final diagnosis.

## Features
- Accepts user symptoms as input
- Uses IF-THEN rules for decision making
- Implements Forward Chaining
- Supports multi-step inference
- Displays inference steps (reasoning path)
- Suggests possible diseases based on symptoms

1. Install Python 3.
2. Open the project folder in Visual Studio Code.
3. Open the terminal.
4. Run the following command:

```bash
python expert_system.py
```
